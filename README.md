 AI News Intelligence System

An autonomous AI-powered news research agent that collects AI news from RSS feeds, processes articles, generates summaries, classifies topics, and presents insights through an interactive dashboard.

Overview

AI News Intelligence System automates the complete news research workflow:

Collect → Analyze → Summarize → Categorize → Deliver

The system uses AI agents to transform raw news articles into structured intelligence.

✨ Features

- 📰 Collects AI news from multiple RSS sources
- 🔍 Extracts and processes article content
- 🤖 AI-powered article summarization
- 🏷️ Automatic category classification
- 💾 Stores processed data using SQLite database
- 📊 Interactive Streamlit dashboard
- 🔎 Search and category filtering
- ⚡ Automated news intelligence pipeline
